# Kho Ứng Dụng TV LG (AV Sport & AV Movie)

Kho ứng dụng chính thức cho Smart TV LG webOS, tích hợp tự động cập nhật 1 chạm qua **webOS Homebrew Channel**.

## 📺 Danh Sách Ứng Dụng

| Tên Ứng Dụng | Phiên Bản | Thể Loại | Tải Về Trực Tiếp |
| :--- | :--- | :--- | :--- |
| **AV Sport** | 1.0.8 | Trực tiếp Thể thao / Bóng đá | [Tải IPK](releases/com.anhviet.avsport.tv_1.0.8_all.ipk) |
| **AV Movie 4K** | 1.2.3 | Phim ảnh / Hoạt hình / 4K | [Tải IPK](releases/com.avmovie.webos_1.2.3_all.ipk) |

---

## 🚀 Hướng Dẫn Cập Nhật Tự Động 1 Chạm Trên TV (Homebrew Channel)

1. Mở ứng dụng **Homebrew Channel** trên TV LG.
2. Bấm vào biểu tượng **Settings** (bánh răng cưa) ở góc trên.
3. Chọn mục **Repositories** -> Chọn **Add Repository**.
4. Nhập đường dẫn sau:
   `	ext
   https://raw.githubusercontent.com/anhviet-key/tivi_lg/main/apps.json
   `
5. Bấm **Add**.
6. Từ nay, cả 2 app **AV Sport** và **AV Movie** sẽ hiển thị trong Homebrew Channel. Khi có bản cập nhật mới, TV sẽ tự báo chấm đỏ, bạn chỉ cần bấm **Update** bằng remote là xong!
